# 포켓몬 윷놀이 v10 — 👤 프로필 (사람마다 이름 · 캐릭터 · 기록 · 저장 코드)

> 상태: **구현 완료** (2026-10-02, `APP_VERSION 2026-10-02a`)
> 사용자 확정: "각자 이름과 보유한 포켓몬으로 캐릭터로 프로필을 정할 수 있고 코드로 저장" · 기록은 **프로필마다 따로** · 캐릭터는 **내 포켓몬 중에서**
> [v9 저장 코드](v9-저장코드.md)를 프로필마다로 바꾼 것

## 1. 한눈에

```
처음 화면 👤 프로필
  ├ 🧒 지온이 (캐릭터 이브이)  📕 3마리 · 🎒 볼 7개 · 🏆 12판   [✏️ 꾸미기] [💾 저장 ✓] [🗑️]
  ├ 👩 엄마 …
  ├ ➕ 새 프로필 (이름 쓰기 + 캐릭터 고르기)
  └ 📥 코드로 불러오기
가족 대결 · 로켓단 대결 준비: 팀을 프로필로 고른다 (캐릭터 얼굴 + 이름, ➕ 새 프로필)
친구 대결: 방 만들 때 · 코드로 들어갈 때 "누가 할까요?" 프로필 고르기 (이름 쓰기 대신)
```

## 2. 정한 것

| 곳 | 정한 것 |
| --- | --- |
| 프로필 | 이름(8글자까지) · 캐릭터 포켓몬 · 📕 잡은 포켓몬 · 🎒 볼 · 🏆 전적 · 🎓 공부 기록 · 지난번 고른 포켓몬 · 💾 저장 코드 — **사람마다 따로** |
| 처음 | ✅ (2026-10-02 바뀜) **하나만** 만든다 — 이름은 **"꿈꾸는아이"** (2026-10-02 사용자 요청, ✏️ 꾸미기에서 바꿈) — 더 필요하면 ➕ 새 프로필. **예전 기록(패드 하나에 모은 것)은 지온이 것으로** (가족 대결 이긴 사람이 있으면 그 사람 프로필도 만들어 이긴 수를 옮김). 예전 버전이 만든 가족 6명 중 **한 번도 안 쓴 프로필**(이름 그대로 · 포켓몬 0 · 판 0 · 저장 안 함 · 볼 그대로 · 공부 기록 없음)은 한 번 치운다. 시험용 `?fam=1` = 가족 6명 |
| 가족 대결 | 프로필이 하나뿐이면 두 번째 팀 줄에 "➕ 새 프로필로 만들어 주세요" — 만들면 바로 두 번째 팀으로, 두 번째 팀 없이는 고르기로 안 넘어감 |
| 새 프로필 | 이름 쓰기 + 캐릭터(스타팅 27마리 중) → 처음 선물 몬스터볼 3개, 포켓몬 0 |
| 캐릭터 | **그 사람의 포켓몬 중에서** (스타팅 27 + 그 사람이 잡은 포켓몬). 잡을수록 고를 게 늘어남. 팀 카드 이름 옆 · 판 위 말의 팀 표시 · 동전 던지기 이름판 · 고르기 화면 "찜" 표시에 나온다 |
| 판 | 팀 = 프로필. 풀숲에서 잡은 포켓몬 · 쓴 볼 · 시계 문제 기록은 **그 팀 프로필**에. 로켓단 대결 상자 · 돈 문제는 사람 팀 프로필, 친구 대결 상자는 이 패드의 내 프로필. 가족 대결은 두 사람 모두 판 수 · 이김/짐 |
| 고르기 | 그 팀 프로필의 포켓몬에서 (스타팅 + 그 사람이 잡은 것) |
| 가방 · 전적 | 창 위에서 프로필을 골라 본다 (판에서는 지금 차례인 사람 것부터) |
| 지우기 | **"지우기"를 써야** 지운다 (이 패드에서만 — 저장 코드가 있으면 서버 기록은 남아 다시 불러올 수 있음). 마지막 하나는 못 지움 |
| 기술 도감 | 본 기술은 패드 하나에 같이 |
| 저장 코드 | **프로필마다 하나** (숫자 6자리). 그 사람 기록이 바뀌면 저절로 저장 |
| 불러오기 | 코드 → 그 프로필이 이 패드에 **생긴다**. 같은 프로필(같은 사람)이 이미 있으면 "불러오기"를 써서 바꾸기. 친구네 패드에 내 프로필을 불러와서 할 수도 있다 |
| 패드 두 대 | 같은 프로필이면 잡은 포켓몬은 합치고, 볼 · 전적 · 공부 기록 · 이름 · 캐릭터는 나중에 저장된 쪽 |

## 3. 서버 자료

`yutsaves/{6자리}` = `{ v: 2, updated, dataJ: "{ id, name, avatar, collection, bag, stats, study }" }` — Firebase 규칙은 [v9 5장](v9-저장코드.md) 그대로 (`yutsaves`)

## 4. 시험

- `tools/test-ui.py` `scenario_save`: 예전 기록 → 지온이 · 프로필 화면 · 꾸미기(캐릭터 = 내 포켓몬) · 새 프로필(이름 필수, 볼 3개) · 프로필마다 코드 · 저절로 저장(그 사람 코드에만) · 다른 패드: 틀린 코드 / 같은 프로필 글자 확인 / 없는 프로필 바로 생김 · 합치기 · 끄기 · 지우기 · 가족 대결 팀 = 프로필, 잡은 포켓몬은 그 팀 프로필에
- `scenario_net`: 코드로 들어갈 때 ➕ 새 프로필 "하윤이네"를 만들어 고르기
