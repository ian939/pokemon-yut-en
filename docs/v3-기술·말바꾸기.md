## 1. 한눈에

```
윷판을 달림 ─ 5칸마다 ─▶ ✨ 진화 ─ 마지막 모습 ─▶ 📖 기술을 배움 (타입 따라 무작위)
                                                      │ 말마다 한 판에 한 번
                                                      ▼
                                             내 차례에 ✨ 기술 쓰기
🌿 ❓ 풀숲에서 잡음 ─▶ 🔄 그 자리에서 말 바꾸기 ─▶ 새 포켓몬 = 기술 한 번 더
```

- 기술이 **무작위**라서 "리자몽이 이번엔 무슨 기술을 배울까?"가 판마다 다르다
- 기술은 **말마다 한 판에 한 번** → 다 쓴 말을 새로 잡은 포켓몬과 바꾸면 **한 번 더**. ❓ 풀숲에 갈 이유가 더 커진다
- 윷놀이 규칙(도·개·걸·윷·모, 업기, 잡기, 지름길)은 그대로. 기술은 그 위에 얹는 양념

## 3. 진화 — 5칸마다

- 말마다 **앞으로 간 칸 수**를 센다 (윷·기술 모두). 5칸이면 한 단계, 10칸이면 두 단계
  - 스타팅 포켓몬(3단계): 5칸에 두 번째 모습, **10칸에 마지막 모습** → 이때 기술을 배운다
  - 2단계 포켓몬은 5칸에 마지막 모습. 진화하지 않는 포켓몬은 처음부터 마지막 모습 (❓ Q8)
- 빽도나 밀려나기로 뒤로 가도 **빼지 않는다** (진화가 되돌아가지 않음)
- 잡히면 **처음 모습**으로 돌아가고, 센 칸도 0부터 (지금 규칙 그대로)
- 지름길로 가도 칸 수대로 센다. 지금은 지름길로 가면 진화가 빨라지지만, 이제는 그렇지 않다 (칸 수가 아이에게 더 알기 쉽다)
- 화면: 팀 카드 포켓몬 칩의 아래 모서리에 **점 5개**(다음 진화까지 남은 칸). 그림을 가리지 않게

## 4. 🔄 말 바꾸기 — 잡은 포켓몬을 바로 말로

1. 풀숲에서 잡으면 → "이브이를 지금 말로 쓸까요?"
2. 내 말 중 하나를 고른다 (골인하지 않은 말: 판 위·집 모두). **기술을 다 쓴 말**에는 "✨ 다 씀" 표시 → 바꾸면 새 기술을 쓸 수 있다
3. "돌아와, 리자몽!" → "가라, 이브이!" → 그 자리(업혀 있으면 업힌 채로)에서 이브이로 바뀐다
4. "나중에"를 고르면 지금처럼 보관함에만 넣는다 (다음 판부터)

| 항목 | 제안 |
| --- | --- |
| 자리 | 바뀐 말의 칸·업힌 상태 그대로 |
| 진화 단계 | ✅ **이어받기** — 바뀐 말이 간 칸 수를 이어받아 곧바로 진화한다. 10칸 간 리자몽 자리에 이브이 → 바로 샤미드·부스터… 중 하나 → 기술도 바로 배움. 단계 = 잡은 모습 + (간 칸 수 ÷ 5), 마지막 모습까지 |
| 들어오는 모습 | 잡은 모습 그대로 (리자드를 잡았으면 리자드). 잡히면 그 모습으로 돌아간다 |
| 기술 | 새 포켓몬은 기술을 **새로** 배운다. 다 쓴 기록은 나간 포켓몬 것 |
| 마비·잠 | 바꾸면 사라진다 (새 포켓몬은 깨끗한 상태) |
| 같은 가족 | 판 위(두 팀 모두)에 같은 진화 가족이 있으면 못 바꾼다. 그 가족인 말을 바꾸는 건 된다 (파이리 말 → 잡은 리자몽 ✅) |
| 기술 횟수 | 말 바꾸기는 "한 차례에 기술 하나"(Q4)에 세지 않는다 |

## 5. 😈 로켓단 — "로켓단도 잡으면 그 포켓몬으로" ✅ A + C (2026-09-26)

뜻이 셋일 수 있어서 물었고, **A와 C**로 정했다.

| 안 | 내용 | 바뀌는 것 |
| --- | --- | --- |
| **A ✅** | 로켓단도 ❓ 풀숲에서 **그물로 잡아 자기 말로** 바꾼다 | 지금은 쫓아내기만 한다 → "로켓단이 그물로 이브이를 잡아 갔다옹~!" (그물은 한 번, ❓ Q7 60%). 로켓단이 잡은 포켓몬은 그 판에서만 (보관함 없음). 바꿀 말은 기술을 다 쓴 말 → 집에 있는 말 → 멈춘 말 순서 |
| B (안 함) | 내가 로켓단 말을 배틀로 물리치면 **그 포켓몬을 데려와** 내 말로 | 데려온 포켓몬은 내 보관함에도 들어간다. 로켓단은 그 말 대신 대타 포켓몬(꼬렛·주뱃 등)을 불러 집에서 다시 출발 |
| **C ✅** | 로켓단 대결에서도 **내가** 풀숲에서 잡은 포켓몬으로 바꾼다 | 가족 대결과 같은 규칙이라 새로 만들 것 없음 |

- 그래서 ❓ 풀숲은 **먼저 멈추는 쪽이 임자** — 로켓단보다 먼저 가야 한다. 로켓단이 잡은 포켓몬 말을 배틀로 물리치면 보통 잡기처럼 집으로 돌아갈 뿐, 데려오지는 않는다
- 로켓단이 바꿔 넣은 포켓몬도 이어받기(U9)·기술(U10) 규칙이 똑같다. 로켓단 그물은 볼 가방을 쓰지 않는다
- (나중에 생각해 볼 것) B의 "로켓단이 훔쳐 간 포켓몬 되찾기" — 로켓단 말을 물리치면 그 포켓몬을 구해 내 보관함으로

## 6. ✨ 기술 — 공통 규칙

| 규칙 | 내용 |
| --- | --- |
| 배우기 | 마지막 모습이 되는 순간 **무작위로 하나** 배운다: "리자몽은 공중날기를 배웠다!" 전설(과 Q8의 진화하지 않는 포켓몬)은 판을 시작할 때 배운다. 뽑은 기술은 판에 저장돼서 새로고침해도 같다 |
| 후보 | ✅ 그 포켓몬 **타입의 기술들**. 예: 리자몽(불꽃·비행) → 니트로차지·화염방사·공중날기·순풍 중 하나 |
| 쓰기 | **내 차례에, 판 위에 나와 있는 말**만 쓴다. 윷을 던지기 전이든 말을 고를 때든 (기술마다 정해진 때가 있는 것도 있다) |
| 횟수 | 말마다 **한 판에 한 번**. 잡혀서 처음 모습이 돼도 안 쓴 기술은 남는다 (다시 마지막 모습이 되면 쓸 수 있다) |
| 한 차례 | ✅ **하나** — 차례가 길어지지 않고, 여러 기술을 한꺼번에 이어 쓰는 복잡한 수가 안 생긴다 (말 바꾸기는 세지 않음) |
| 두 종류 | **누르는 기술**(내가 골라 씀) · **저절로 기술**(🥊 카운터 · 🛡️ 철벽 · 🌙 달빛 · 👻 길동무 — 때가 되면 알아서 나가고, 그때 쓴 걸로 친다) |
| 골인 | 골인한 말의 기술은 없어진다 |
| 끄기 | 판 설정에 **✨ 기술 켜기 / 끄기** (끄면 지금 윷놀이 그대로) |

| 얼음 | 흑안개 | 판 위의 효과를 모두 깨끗이! 🌫️ | 아무 때 | 마비·잠·독·봉인·장막·비·바위·거미줄 전부 (우리 것도). 당하기만 하지 않게 |
| 비행 | 순풍 | 우리 말이 모두 한 칸씩 앞으로 🍃 | 아무 때 | 지진의 반대. 순풍으로는 잡지 않는다 (상대가 바로 앞이면 그 말은 그대로) |
| 에스퍼 | 사이드체인지 | 판 위의 우리 말 두 개가 자리를 바꿔요 🔄 | 아무 때 | 뒤처진 말을 앞으로, 위험한 말을 뒤로 |
| 벌레 | 끈적끈적네트 | 빈 칸에 거미줄! 상대가 지나가다 걸려서 멈춰요 🕸️ | 아무 때 | 윷놀이에만 있는 "지나가기"를 쓰는 함정 |
| 고스트 | 길동무 | 이 말이 잡히면 잡은 상대도 같이 집으로! 👻 | 저절로 | 잡혀도 억울하지 않게 |

→ 타입마다 1~2개, 모두 27개. 스타팅 포켓몬 27마리의 마지막 모습은 후보가 2~4개씩이다 (리자몽 4개, 거북왕 2개, 엠페르트 3개, 모크나이퍼 4개 …).

### 7-3. 기술 뽑기

- 후보 = **배우는 순간 모습의 타입** 기술들, 하나씩 같은 확률 (✅ U10 — 전체에서 뽑는 "깜짝"은 하지 않는다)
- 이브이처럼 진화 갈래가 여럿이면 어느 모습이 되느냐에 따라 타입이 달라져서 두 번 놀란다
- 뽑기는 판 시드 난수 → 새로고침해도 같고, 테스트에서 결과를 정할 수 있다

## 8. 부딪힐 때 규칙

### 8-1. 밀기 (파도타기 · 지진)

- 한 칸씩 뒤로 (빽도와 같은 길). **1칸째보다 뒤로는 안 간다** (참먹이로 밀리면 바로 골인할 수 있게 되는 걸 막기)
- 밀린 칸에 **민 팀 말이 있으면 그 앞에서 멈춘다** (밀려서 잡거나 잡히는 일은 없다)
- 밀린 칸에 자기 팀 말이 있으면 업힌다. 업힌 말은 같이 밀린다
- 밀린 칸의 ❓ 풀숲·바위·거미줄은 **안 걸린다** (자기 이동으로 멈출 때만)
- 장막(❄️) 말은 안 밀린다

### 8-2. 기술로 움직이기 (니트로차지 · 공중날기 · 용의춤 · 유턴)

- 보통 이동과 똑같다: 상대 칸이면 **배틀** + 한 번 더, 우리 말이면 업기, ❓ 풀숲이면 조우, 바위·거미줄도 걸린다
- 순풍(모두 움직이기)만 예외: 잡지 않고 풀숲·함정도 안 걸린다 (여러 장면이 한꺼번에 겹치지 않게)

### 8-3. 잡힐 때 저절로 나가는 기술 — 순서

1. 🛡️ **철벽** — 업힌 말 중 하나라도 있으면 잡기 자체를 막는다 (상대는 온 자리로, 한 번 더 없음)
2. 🌙 **달빛** — 그 말만 한 칸 뒤로 (갈 칸이 없으면 집으로)
3. 👻 **길동무** — 잡은 상대 말도 집으로

- 화염방사로 잡혀도 똑같다 (철벽이면 불꽃을 막아 낸다)
- 바위(스텔스록)에 걸리는 건 잡기가 아니라서 저절로 기술이 안 나간다

### 8-4. 카운터 — 되돌리는 표

| 상대가 쓴 기술 | 되돌아가면 |
| --- | --- |
| 파도타기 · 전기자석파 · 수면가루 · 화염방사 | 그 기술을 쓴 말이 2칸 밀림 · 마비 · 잠 · 집으로 |
| 지진 | 상대 말이 모두 한 칸 뒤로 |
| 맹독 · 원한 | 상대 팀 다음 윷이 빽도 · 상대 팀 기술 봉인 |
| 가로챈다 | 빼앗기지 않는다 (막기만) |

- 카운터 말이 판 위에 있어야 나간다. 장막(❄️)이 있는 말은 애초에 기술을 맞지 않는다

### 8-5. 그 밖

- 마비·잠: 못 움직이고 누르는 기술도 못 쓴다 (저절로 기술은 나간다). 그 말에 업히면 같이 못 움직인다
- 봉인 중에도 기술을 배우기는 하지만 쓰지는 못한다
- 맹독과 비바라기가 겹치면 비가 이긴다 (빽도 → 개)
- 표시: 효과는 **말·팀 카드의 모서리에 작게**(⚡ 💤 ❄️ ☠️ 🔒 🌧️), 칸에는 🪨 🕸️. 포켓몬 그림을 가리지 않게, 크기는 말의 %로

## 10. 로켓단(컴퓨터)의 기술

- 🌱 쉬움: **상대를 방해하는 기술은 안 쓴다** (이동·던지기·지키기 기술만). 쓸 수 있어도 가끔만 (30%)
- 🔥 보통: 쓸모 있을 때 쓴다 (잡을 수 있으면 화염방사, 상대 말이 둘 이상 나와 있으면 지진, 가장 앞선 상대 말에 파도타기·마비 …)
- 저절로 기술은 누구나 똑같이 나간다
- Q5 (제안값으로 만듦): 로켓단도 마지막 모습까지 진화 — 아보→아보크, 또가스→**또도가스**, 나옹→**페르시온**(또는 퍼옹), 마자→마자용 (모두 5칸에 기술)
- `sim-cpu.js` 결과 (1,500판, 아이 = 아무렇게나 두는 스타팅 팀): 말 4개 — 🌱 쉬움 상대 아이 승률 **55.5%** (기술 없을 때 51.5%) · 🔥 보통 상대 **25.9%** (25.6%). 기술이 로켓단을 더 세게 만들지 않는다

## 11. 설계

### 11-1. 판 상태 (저장 v2 → v3)

```js
pieces[i] += { walk: 0, base: 0, skill: null, used: false, fx: { para: 0, sleep: 0, veil: 0 } }
//   walk: 앞으로 간 칸 수 (5칸마다 진화) · base: 처음 모습의 단계 (바꿔 들어온 말은 잡은 모습)
teams[t] += { pools: [[...]], early: [false, …], fx: { poison: false, seal: 0, rain: 0 } }
//   pools[slot]: 배울 수 있는 기술 후보 — 화면이 타입을 보고 정해 넘긴다 (엔진은 포켓몬 데이터를 모른다)
//   early[slot]: 전설 → 처음부터 배움
state += { traps: [{ node, kind: "rock" | "web", team }], skillTurn: 0 }   // skillTurn: 이 차례에 기술을 썼나
settings += { skills: true }
```

- 옛 저장(진행 중인 판)은 불러올 때 빈 값을 채워서 이어 한다 (walk는 지금까지 온 걸음 수로)

### 11-2. 엔진 함수

```js
Yut.SKILLS        // { key: { name, type, kind: "active" | "react", when: "any" | "throw" | "pending", target } }
Yut.TYPE_SKILLS   // { "불꽃": ["nitro", "flame"], "물": ["surf", "rain"], … }
legalSkills(state)                      // 지금 쓸 수 있는 기술과 대상
applySkill(state, piece, target)        // → { state, events }
applySwap(state, piece, { id, path, base, pool, early })   // 말 바꾸기
applyThrow(state, forced, guess)        // 미래예지·희망사항·맹독·비바라기 반영
cpuSkill(state, level, rnd)             // 로켓단이 쓸 기술 (없으면 null)
```

- 이벤트 추가: `learn · skill · push · status · trap · block(철벽) · moon(달빛) · bond(길동무) · reflect(카운터) · steal · swap`
- 저절로 기술은 `applyMove`·`applySkill` 안에서 처리한다. 화면은 지금처럼 이벤트를 차례대로 연출만 한다
- 상태는 연출 전에 먼저 저장 (지금 원칙 그대로 — 기술 장면 중에 패드를 꺼도 판이 안 꼬인다)

### 11-3. 화면 쪽

- 말마다 `pools`(마지막 모습 타입의 기술)를 계산해서 `newGame`에 넘긴다. 바꿔 들어온 말은 `applySwap`에 넘긴다
- 풀숲에서 잡으면 → 바꿀 말 고르기 → `applySwap` → 저장 → 연출 (조우 무대 안에서)
- 기술 컷인은 새 `cutIn()` (1.5초). 화염방사는 배틀 무대(`openStage`)를 그대로 쓴다

## 14. 조심할 것

- **아이가 속상하지 않게**: 집으로 보내는 기술(화염방사·스텔스록)은 말마다 한 판에 한 번뿐이고, 로켓단 쉬움은 방해 기술을 안 쓴다. 당해도 되갚을 수 있는 기술(카운터·길동무·흑안개)이 있다
- **차례가 길어지지 않게**: 한 차례에 기술 하나, 컷인은 1.5초이고 누르면 넘어간다
- **글자는 짧게**: 기술 설명은 한 줄. "지름길 입구" 같은 말 대신 "모서리"
- **양이 크다**: 기술 27개와 부딪힘 규칙이 이번 버전에서 가장 큰 일이다. 초안 18개로 먼저 만들고 추가 9개를 나중에 넣어도 된다

## 17. 🎁 기술 넘겨주기 (2026-09-27, `2026-09-27c`, 사용자 확정)

전에는 "골인한 말의 기술은 없어진다"였다 → 바꿈.

| # | 정한 것 |
| --- | --- |
| G1 | 기술을 못 쓰고 골인하면(제 기술·받은 기술 모두) 그 기술을 **받을 팀원을 고른다** (골인하지 않은 팀원, 집에 있어도 됨) |
| G2 | 말 하나가 기술을 **두 개**까지: 제 기술 + 🎁 받은 기술. 받은 기술을 이미 들고 있는(안 쓴) 팀원은 후보에서 빠진다 |
| G3 | 제 기술을 **다 썼다면 받은 기술만** 쓸 수 있다. 둘 다 남았으면 둘 중 하나를 골라 쓴다 (한 차례에 하나는 그대로) |

- 받은 기술은 **칸 수와 상관없이** 판 위에서 바로 쓴다 (이미 배운 기술이라서). 저절로 기술(철벽·달빛·길동무·카운터)도 받으면 저절로 나간다
- 로켓단은 알아서 준다: 판 위의 기술 없는 말 → 판 위의 말 → 집의 기술 없는 말
- 받을 팀원이 없으면(모두 골인·모두 받은 기술을 듦) 사라진다. 마지막 말이 골인해서 이기면 넘기지 않는다
- 고르기 창은 연출이 끝난 뒤 뜨고, 닫아도 다시 물어본다 (새로고침해도 `gifts` 줄이 판에 저장돼 있어서 다시 뜸)
- 엔진: `pieces[i].gift = { key, used }` · `state.gifts = [{ team, from, key }]` · `applyGift(state, to)` · `giftTargets` · `legalSkills` 항목에 `slot: "own" | "gift"` · `applySkill(state, i, target, slot)`
- 화면: 칩 왼쪽 아래 🎁(쓰면 ✓), 기술 창에 "🎁 받은 기술" 표시, 기술 보기 창에 받은 기술
- 검사: 규칙 65개(넘기기·두 개·받은 것만·칸 무관·저절로·후보 빠짐·이기면 안 넘김·로켓단 자동·저장 검사·무작위 3,000판에서 넘기기) · 화면 154개
