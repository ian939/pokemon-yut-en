## 1. 한 줄 요약

**스타팅 포켓몬과 윷판에서 잡은 포켓몬이 말이 되어, 가족끼리 한 패드로 윷놀이를 하는 게임.**
윷놀이 규칙은 그대로 두고, 말·윷 결과·잡기·완주를 포켓몬식으로 보여 줍니다.

## 2. 누가, 언제 하나

| 항목 | 내용 |
| --- | --- |
| 주 사용자 | 초1 아이 (잉글리시몬을 하는 아이) |
| 같이 하는 사람 | 엄마·아빠·이모·할머니 — **패드 한 대를 돌려 가며** 함 (한 기기 번갈아 하기) |
| 혼자 할 때 | 로켓단(컴퓨터)과 대결 |
| 한 판 시간 | 10~15분 (말 4개 기준). 짧은 판(말 2개)은 5분 안팎 |
| 기기 | 아이 패드 (가로 화면 기본, 세로도 깨지지 않게) |

## 3. 목표

1. **가족이 같이 앉아서 하는 놀이** — 잉글리시몬은 혼자 하는 게임이라, 같이 할 거리를 만든다.
2. **하나씩 늘려 가는 재미** — 처음엔 스타팅 포켓몬뿐이고, 윷판의 ❓ 풀숲에서 잡을 때마다 고를 수 있는 말이 하나씩 늘어난다.
3. **진짜 윷놀이 규칙을 배운다** — 도·개·걸·윷·모, 업기, 잡기, 지름길. 명절에 그대로 쓸 수 있게.

영어 학습이 목표는 아니에요 (연결 방법은 ❓ Q3).

## 4. 핵심 재미 요소

### 4-1. 윷 결과 = 포켓몬
도·개·걸·윷·모가 원래 동물(돼지·개·양·소·말)이라서, 같은 동물 포켓몬이 나와 결과를 알려 준다.

| 결과 | 칸 | 원래 동물 | 등장 포켓몬 | 연출 |
| --- | --- | --- | --- | --- |
| 도 | 1 | 돼지 | 뚜꾸리 (#498) | "도!" 한 칸 |
| 개 | 2 | 개 | 가디 (#58) | |
| 걸 | 3 | 양 | 메리프 (#179) | |
| 윷 | 4 | 소 | 켄타로스 (#128) | **한 번 더!** 배너 |
| 모 | 5 | 말 | 포니타 (#77) | **한 번 더!** + 큰 연출 |
| 빽도 | -1 | — | 야돈 (#79) | "뒤로 한 칸~" (느릿느릿한 야돈) |

→ 아이가 "걸이 몇 칸이지?"를 포켓몬으로 외운다. 결과 이름은 소리로도 읽어 준다 (한국어 TTS).

### 4-2. 말 = 내 포켓몬 (+ 진화)
- 게임을 시작할 때 **팀마다 포켓몬을 말 수만큼 고른다**. 고르기 화면은 두 칸이다:
  - **🌱 스타팅 포켓몬 27마리** — 1~9세대 풀·불꽃·물 스타팅 (이상해씨·파이리·꼬부기 … 나오하·뜨아거·꾸왁스). 처음부터 누구나 고를 수 있다.
  - **🎯 잡은 포켓몬** — ❓ 풀숲에서 잡은 포켓몬이 **잡은 순서대로** 뒤에 하나씩 붙는다. 아직 없으면 "❓ 풀숲에서 포켓몬을 잡으면 여기에 하나씩 늘어나요!" 안내.
  - (처음 버전은 잉글리시몬 도감에서 골랐다. 2026-09-25에 바꿈 — 스타팅에서 시작해 잡아서 늘려 가는 재미를 주려고)
- **진화 연출** (v1 포함 — 확정): 말은 **진화 라인의 1단계 모습으로 출발해, 마지막 모습까지** 윷판을 돌면서 진화한다.
  - 예) 파이리로 출발 → 5칸 가면 리자드 → 10칸 가면 리자몽 → "골인!" (v3: **5칸마다** — 전에는 길의 1/3·2/3 지점)
  - 마지막 모습이 되면 ✨ **기술**을 하나 배운다 → 4-6
  - 갈래가 여럿이면(이브이 → 샤미드·쥬피썬더·… , 랄토스 → 가디안·엘레이드) **판마다 무작위로 한 갈래**. 고르기 칸에는 "… › ?"로 보여서 어디로 진화할지 궁금하게 둔다.
  - 잡은 포켓몬이 진화형이어도(예: 리자드) 1단계부터 출발해 마지막 모습까지 간다.
  - 잡히면 1단계로 돌아가 몬스터볼에 들어간다.
  - 진화하지 않는 포켓몬(전설 등)은 모습 그대로 → 대신 반짝이 효과.
- **한 진화 가족에서 한 마리만** 고른다 (내 팀·상대 팀 모두). 리자몽과 리자드를 같이 고르면 판 위에 똑같은 파이리가 둘 생겨서 헷갈리기 때문.
- 지난 판에 고른 포켓몬이 사람별로 미리 채워진다. "🎲 알아서 골라 줘"는 고를 수 있는 포켓몬 중에서 무작위로 채운다.
- 대기 중인 말은 패널의 몬스터볼 포켓몬으로 보이고, **어느 포켓몬을 먼저 낼지 아이가 고른다.**

### 4-3. 잡기 = 포켓몬 배틀!
- 상대 말이 있는 칸에 멈추면 **배틀 화면**이 뜬다: 내 포켓몬(뒷모습)과 상대(앞모습)가 발판 위에 서고, "리자몽의 화염방사!" 기술로 상대 HP를 줄여 **물리친다**. 쓰러지는 장면은 없다.
- 진 포켓몬은 **집(출발 자리)으로 달려 돌아가** 처음부터 다시 출발한다. 뺏기는 게 아니다.
- 이기면 **한 번 더 던지기**. 배틀이 길면 "건너뛰기".
- 판 설정의 **배틀 장면 ⚔️ 보기 / ⏭ 건너뛰기** (2026-09-25 추가): 건너뛰기를 고르면 배틀 화면 없이 💥 + "지온이의 파이리가 꼬부기를 물리쳤다!" 한 줄만 보이고 바로 집으로 돌아간다. 판을 빨리 돌리고 싶을 때. 설정은 저장되어 다음 판에도 그대로.
- 몬스터볼은 배틀에 쓰지 않는다 (2026-09-25 바꿈) — 볼은 ❓ 풀숲 야생 포켓몬에게만 ([v2 계획](v2-보물상자·야생포켓몬.md)).

### 4-4. 업기 = "같이 가자!"
- 내 말끼리 같은 칸에 서면 자동으로 업는다 → 포켓몬이 겹쳐서 쌓이고 "×2" 배지가 모서리에 붙는다.

### 4-5. 로켓단 대결 (혼자 하기)
- 로켓단(무사시·로이·나옹)이 아보크·또가스·나옹·마자용을 말로 데리고 온다.
- 잉글리시몬에서 쓰는 로켓단 도트 그림(`img/rocket-*.png`)을 그대로 쓴다.
- 등장 대사도 잉글리시몬과 같게: "귀염둥이 악당, 포켓몬의 감초~!"
- 난이도 2단계 — 상대가 아이라서 약하게 맞췄다 (시뮬레이션으로 확인):
  - 🌱 쉬움: 아무 데나 둔다 → 아무렇게나 두는 상대와 거의 반반 (47%)
  - 🔥 보통: 절반은 똑똑하게(잡기·지름길·위험 피하기) → 73%
- 로켓단이 잡으면 "로켓단이 잡았다옹~!", 지면 "로켓단은 또 지는 거냐옹~!"
- v3: 로켓단도 기술을 쓴다 — 🌱 쉬움은 상대를 방해하는 기술은 안 쓰고 가끔만, 🔥 보통은 쓸모 있을 때. 로켓단 말도 마지막 모습까지 진화한다 (또도가스·페르시온…). 풀숲에서는 그물로 포켓몬을 잡아 간다.


### 4-6. ✨ 기술 · 🔄 말 바꾸기 (v3)
- 마지막 모습이 되는 순간 그 포켓몬 **타입의 기술 중 하나를 무작위로** 배운다 ("리자몽은 공중날기를 배웠다!"). 전설·진화하지 않는 포켓몬은 처음부터.
- 내 차례에 **✨ 기술** 버튼으로 쓴다 — 말마다 한 판에 한 번, 한 차례에 하나. 기술 27개(니트로차지·파도타기·지진·스텔스록·미래예지…)와 저절로 나가는 기술 4개(카운터·철벽·달빛·길동무).
- ❓ 풀숲에서 잡으면 "지금 말로 쓸까요?" → 내 말 하나와 **그 자리에서 바꾼다**. 간 칸 수를 이어받아 곧바로 진화해서, **기술을 다 쓴 말과 바꾸면 새 기술을 또 쓴다**.
- 로켓단도 풀숲에 멈추면 그물로 잡아 자기 말로 바꾼다 (한 번, 60%). 풀숲은 먼저 멈추는 쪽이 임자.
- 준비 화면에서 **✨ 기술 켜기/끄기** (두 대결 모두). 자세한 규칙·기술 표는 [v3 계획](v3-기술·말바꾸기.md).

## 5. 게임 흐름

```
[홈]
 ├─ 👨‍👩‍👧 가족 대결 ──┐
 └─ 😈 로켓단 대결 ─┤
                    ▼
[판 설정] 말 수(2·3·4) · 빽도 켜기/끄기 · ✨ 기술 켜기/끄기 · 배틀 장면 보기/건너뛰기 · (로켓단이면 난이도)
                    ▼
[팀 고르기] 팀 이름(지온이/엄마/아빠…) → 포켓몬 N마리 고르기 (스타팅 + 잡은 포켓몬)
                    ▼
[윷판] ── 던지기 → 결과 포켓몬 등장 → (윷·모·잡기면 또 던지기) → 말 고르기 → 이동 ──┐
   ▲                                                                           │
   └────────────────────────── 다음 팀 차례 ◀──────────────────────────────────┘
                    ▼ (한 팀의 말이 전부 들어오면)
[결과] 이긴 팀 포켓몬 전원 등장 + 🎉  → [한 판 더] / [홈]
```

- **진행 중인 판은 자동 저장** → 패드를 끄거나 앱을 나갔다 와도 이어서 한다 (밥 먹고 와서 계속).
- 잉글리시몬 홈에서 들어오는 버튼, 윷놀이에서 잉글리시몬으로 돌아가는 버튼 (❓ Q5).

## 7. 아이를 위한 화면 원칙

(전역 규칙 그대로 적용)

- **확대·복사 막기를 처음부터** 넣는다 — 두 손가락이 닿거나 오래 눌러도 화면이 바뀌지 않게.
- 누르는 것은 전부 **44×44px 이상**. 윷판 칸은 더 크게 (말을 고를 때 손가락으로 누르기 쉽게).
- 배지(×2, 진화 단계, 팀 색)는 **포켓몬 그림을 덮지 않게 모서리**에, 크기는 말 크기의 %로.
- 움직일 말을 누르면 **도착할 칸이 먼저 반짝** → 한 번 더 누르면 이동 (실수로 잘못 두는 것 방지).
- 되돌릴 수 없는 버튼(판 포기, 기록 지우기)은 **글자를 직접 입력해야** 실행.
- 새 버전이 나오면 알려 주는 창 + 화면 맨 아래 버전 표시 (잉글리시몬과 같은 방식).
- 글씨는 짧게, 소리로도. 결과·차례 안내는 TTS로 읽어 준다 ("엄마 차례예요!").

### 7-1. 그림 방향

- **포켓몬은 PokeAPI 그림을 그대로 가져온다** — 새로 그리지 않는다.
- **윷판·윷가락·멍석·배경은 Codex 이미지 생성으로 직접 그린다** — 포켓몬 그림 옆에 놓아도 한 게임처럼 보이게.
  - 게임판 위(판·칸·윷가락)는 말로 쓰는 **도트 그림 톤**에 맞춘다 (옛날 휴대용 포켓몬 게임 마을 지도 느낌).
  - 첫 화면·결과·우승 화면은 **공식 일러스트 톤**에 맞춘다.
- 한국 윷놀이 느낌을 살린다: 짚으로 엮은 멍석, 나무 윷가락, 한옥 마당, 색동 깃발.
- 그림 목록·만드는 방법·검수는 [기술스펙 4-4](기술스펙.md#4-4-직접-그리는-그림-codex-이미지-생성).
