# 포켓몬 윷놀이 v2 — 보물상자 · 야생 포켓몬 (기획 + 구현 계획)

> 상태: **구현 완료** (2026-09-25, `APP_VERSION 2026-09-25f`) — V1~V4는 사용자가 정함, V5~V10은 제안값으로
>
> 2026-09-25 바꿈 (`2026-09-25h`, 사용자 요청): 풀숲 희귀도 **일반 50 · 레어 30 · 유니크 10 · 전설 10** (전: 60·25·12·3) · 고를 수 있는 포켓몬은 **스타팅 27마리 + 보관함(잡은 순서대로)** — 잉글리시몬 도감은 더 읽지 않음 · 판 설정에 배틀 장면 보기/건너뛰기
>
> 구현하며 정한 것: ① 보물상자 볼은 **이긴 순간 가방에 먼저 넣고**, 상자 여는 장면은 보여 주기만 한다 (새로고침해도 사라지거나 두 번 들어가지 않게 — 검사함) ② 상대 말과의 배틀에는 볼을 쓰지 않는다 (같은 날 사용자 요청: 배틀은 "물리치기") ③ 배틀·조우가 무대 함수(`openStage`)를 같이 쓴다 ④ 테스트용 주소 옵션 `?spots=3:58,12:133` · `?spots=none` · `?catch=1|0` · `?box=master,luxury,poke` · 지금 버전(v1)은 [기획서](기획서.md) · [기술스펙](기술스펙.md)
> ❓ 표시는 정해야 할 것. 괄호 안이 제안값이고, 답이 없으면 제안값으로 만든다. 맨 아래 [정해야 할 것](#8-정해야-할-것)에 모아 두었다.

## 1. 한눈에

```
😈 로켓단 대결에서 이김 ──▶ 🎁 보물상자 ──▶ 🎒 가방에 볼이 쌓임
                                                   │
🌿 윷판의 ❓ 풀숲 칸에 멈춤 ──▶ 야생 포켓몬 조우 ──▶ 가방의 볼을 골라 던짐
                                                   │ 잡으면
                                                   ▼
                             📦 윷놀이 보관함 ──▶ 말로 고를 수 있음
```

- **로켓단 대결**을 할 이유가 생긴다 → 이기면 볼을 모은다
- **가족 대결**에도 새 재미 → ❓ 칸을 먼저 밟으려고 다툰다
- 잡은 포켓몬이 **새 말**이 되니 판마다 고를 거리가 늘어난다
- 볼·보관함은 **윷놀이 것만**이다. 잉글리시몬의 볼·코인·도감은 여전히 건드리지 않는다 (v1 원칙 그대로)

## 2. 볼 — 5단계

| 단계 | 볼 | 상자에서 나올 확률 | 잡을 확률 |
| --- | --- | --- | --- |
| 1 | 몬스터볼 | 50% | 60% |
| 2 | 슈퍼볼 | 30% | 65% |
| 3 | 하이퍼볼 | 10% | 70% |
| 4 | **럭셔리볼** (검정·금색) ✅ | 5% | 75% |
| 5 | 마스터볼 | 5% | **100%** ✅ (원작처럼 — 공식의 예외) |

- 잡을 확률 = **60% + 단계마다 5%** (요청대로), **마스터볼만 100%** (확정). ~~포켓몬 희귀도로는 바꾸지 않는다~~ → 2026-09-27 바꿈: 몬스터볼 기준 일반 60 · 레어 50 · 유니크 40 · 전설 30, 놓칠 때마다 +10% ([v4 계획 11장](v4-시계·돈문제.md))
- 볼이 4종(몬스터·슈퍼·하이퍼·마스터)이라 확률 다섯 개(50·30·10·5·5)를 쓰려면 한 종류가 더 필요하다 → 4단계에 **럭셔리볼**을 제안. PokeAPI 아이템 도트가 있다 (`luxury-ball.png` 확인). 다른 후보: 프리미어볼·퀵볼·드림볼
- 마스터볼은 원작에서 **절대 안 빠지는 볼**이라 아이가 그렇게 알고 있을 가능성이 크다. 공식대로면 80%라서, 5%로 겨우 얻은 마스터볼이 빠지면 많이 속상할 수 있다 → 마스터볼만 100%로 하는 것도 제안
- ❓ **처음 시작 선물**: 몬스터볼 3개 (로켓단을 이기기 전에도 ❓ 칸을 써 볼 수 있게)

## 3. 🎁 보물상자 — 로켓단을 이기면

| 항목 | 내용 |
| --- | --- |
| 언제 | **로켓단 대결에서 이겼을 때만**. 가족 대결·졌을 때는 없음 |
| 한 상자에 | 볼 **3개** ✅ — 한 개씩 따로 50·30·10·5·5로 뽑는다 (1개면 판마다 ❓ 칸 두 개를 다 쓰기 모자람) |
| 받는 방법 | 우승 화면에 상자가 통통 튄다 → "상자를 눌러 열어 봐요!" → 누르면 흔들흔들 → 뚜껑이 열리며 빛 → 볼이 하나씩 튀어나와 이름이 뜬다 → "가방에 넣었어요!" |
| 특별 연출 | 럭셔리볼·마스터볼이 나오면 화면이 번쩍이고 반짝이가 더 많이 |
| 두 번 받기 막기 | 상자를 열기 전에 뽑은 결과를 판에 저장 → 새로고침해도 같은 상자, 연 뒤에는 다시 안 나옴 |
| 다음으로 | 상자를 열어야 "한 판 더 / 처음으로"가 나온다 (볼 받기를 놓치지 않게) |

## 4. 🌿 ❓ 풀숲 칸 — 야생 포켓몬

### 4-1. 규칙

| 항목 | 내용 |
| --- | --- |
| 몇 칸 | 판마다 **2칸** |
| 어디 | 판을 만들 때 무작위. 보통 칸 중에서 고르고, 출발 바로 옆(1·2번)·모서리·방·참먹이는 뺀다. 두 칸은 서로 떨어지게 |
| 보이는 모습 | 처음부터 **풀숲 + "?"** 로 보인다. 어떤 포켓몬인지는 조우할 때 공개 |
| 숨은 포켓몬 | 판을 만들 때 미리 정해서 저장한다 (새로고침으로 다른 포켓몬 뽑기 불가) |
| 언제 나오나 | ❓ 말이 그 칸에 **딱 멈췄을 때만** (지나가면 안 나옴 — 멈춘 칸만 세는 지름길 규칙과 같은 원리) |
| 몇 번 | 한 칸에 한 번. 조우가 끝나면(잡든 놓치든) 풀숲이 사라진다 |
| 누가 던지나 | 멈춘 팀. 가방은 ❓ **가족 공용** (잉글리시몬의 볼·도감을 가족이 함께 쓰는 것과 같게) |
| 로켓단이 멈추면 | ❓ "로켓단이 야생 포켓몬을 쫓아 버렸다옹~!" → 풀숲이 사라진다 (로켓단은 볼을 안 쓴다). ❓ 칸을 서로 먼저 밟으려는 재미 |
| 잡기와 겹치면 | 상대 말 잡기 배틀을 먼저, 그다음 야생 조우 |
| 골인하는 이동 | ❓ 칸을 지나 골인하는 이동은 발동 안 함 |

### 4-2. 나오는 포켓몬

- 희귀도: **일반 50 · 레어 30 · 유니크 10 · 전설 10** (사용자 확정 2026-09-25 — 처음엔 잉글리시몬 모험 조우와 같게 60·25·12·3이었다)
- 50% 확률로 **아직 없는 포켓몬**을 먼저 (스타팅 27마리 + 윷놀이 보관함에 없는 것). 없는 포켓몬이면 이름표에 **NEW!**
- 범위: 1~1025 전체 ❓ (잉글리시몬에서 열린 지역까지로 좁힐 수도 있음)
- 전설이 나오면 잉글리시몬처럼 화면 흔들림 + 섬광

### 4-3. 조우 화면 (배틀 무대를 그대로 씀 — 상대 말과의 배틀에는 볼을 안 쓰고, 볼은 여기서만 쓴다)

```
┌─ 배틀 무대 (도트 배경·발판) ──────────────────────┐
│  [이브이  NEW!  레어  HP ██████]      🌿→ 이브이    │
│                                                   │
│   파이리(뒷모습)            [파이리 · 🧒 지온이]     │
└───────────────────────────────────────────────────┘
┌─ 대화창 ─────────────────────────────────────────┐
│ 어떤 볼을 던질까?                                  │
│  ▶ 몬스터볼 ×3  60%    슈퍼볼 ×1  65%              │
│    마스터볼 ×1  80%    그냥 보내 주기               │
└───────────────────────────────────────────────────┘
```

1. 풀숲이 흔들흔들 → "앗! 야생의 이브이가 튀어나왔다!" (+ 울음소리, NEW!·희귀도 표시)
2. 멈춘 말 포켓몬이 뒷모습으로 나온다 → "가라, 파이리!"
3. **볼 고르기** — 대화창이 DS 메뉴로 바뀐다. 가방에 있는 볼만, 개수와 잡을 확률을 같이 보여 준다. "그냥 보내 주기"도 있다
4. 던지기 → 공이 날아가 빨아들임 → **흔들기**
   - 성공: 세 번 흔들고 딸깍 → 별 + "잡았다!"
   - 실패: 1~3번 흔들다가 튀어나옴 → "앗! 볼에서 나와 버렸다!" (결과를 먼저 뽑고 흔드는 횟수를 맞춰 긴장감을 준다)
5. ❓ 한 조우에 **3번까지** 던질 수 있다. 3번 다 실패하거나 볼이 떨어지면 "이브이는 풀숲으로 도망갔다…"
6. 잡으면 → "이브이를 보관함에 넣었어요! 다음 판부터 말로 쓸 수 있어요" ❓
7. 볼이 하나도 없으면 → "볼이 없어요! 로켓단을 이기면 상자에서 볼을 얻을 수 있어요" → 포켓몬이 도망
8. 건너뛰기: 볼을 고르기 전에는 "그냥 보내 주기"와 같고, 던진 뒤에는 결과만 바로 보여 준다

### 4-4. 📦 보관함 · 말로 등록

- 윷놀이에서 잡은 포켓몬은 윷놀이 저장의 **보관함**에 들어간다 (잉글리시몬 도감에는 쓰지 않는다)
- **등록 방법** ✅: 고르기 화면의 **"🎯 잡은 포켓몬"** 칸(🌱 스타팅 포켓몬 아래)에 **잡은 순서대로** 하나씩 붙고, 다음 판부터 말로 고를 수 있다
  - 다른 안: 잡는 즉시 이번 판의 **대기 중인 말 하나와 바꿀지** 묻기 (판 규칙이 복잡해짐 — 이미 판 위를 달리는 말은 못 바꾼다, 진화 단계는 1단계부터 등)
- 진화 규칙 그대로 — 잡은 포켓몬이 진화형이면 판 위에서는 1단계로 출발해 마지막 모습까지 진화
- 한 진화 가족 한 마리 규칙도 그대로

### 4-5. 가방

- 처음 화면에 **🎒 가방** 버튼 → 볼 5종 개수 + 보관함(잡은 포켓몬 목록, 잡은 순서대로)
- 윷판 화면 패널에도 작게 "🎒 몬스터볼 3 · 슈퍼볼 1" (❓ 칸을 밟기 전에 볼이 있는지 보이게)

## 5. 기술 설계

### 5-1. 저장

`engmon_yut_v1` 에 추가:

```js
bag: { poke: 3, great: 0, ultra: 0, luxury: 0, master: 0 },   // 처음 선물 몬스터볼 3
collection: [{ id: 133, t: 1695600000000, from: "wild" }],    // 윷놀이 보관함
stats: { ..., boxes: 0, wildSeen: 0, wildCaught: 0 },
```

게임 상태(`GameState`)에 추가:

```js
spots: [{ node: 7, id: 133, used: false }, { node: 24, id: 58, used: false }],  // ❓ 풀숲 칸
reward: null | { balls: ["poke", "great", "poke"], opened: false },          // 로켓단 승리 상자 (한 번만)
```

- 옛 저장(`spots` 없음)은 ❓ 칸 없는 판으로 그대로 이어진다
- 가방 증감은 **연출 전에 먼저 저장** (던지는 순간 볼 −1, 잡는 순간 보관함 +1) → 연출 중에 패드를 꺼도 볼이 복사되거나 사라지지 않게

### 5-2. 규칙 엔진 (`yut-rules.js`)

- `newGame(opts)`: `opts.spots`를 그대로 저장한다. 어떤 칸·어떤 포켓몬인지는 화면 쪽이 정한다 (엔진은 포켓몬 데이터를 모르게 유지). 칸 고르기는 `Yut.pickSpotNodes(rng, 2)`로 제공
- `applyMove`: 멈춘 칸이 쓰지 않은 ❓ 칸이면 이벤트 `{ type: "wild", node, id, team }`를 내고 그 칸을 `used`로 바꾼다. 골인 이동·빽도로 참먹이 위에 선 경우는 제외
- 이벤트 순서: `move → capture → stack → evolve → wild → finish → bonus → turn` (진화한 뒤의 모습으로 조우 화면에 나오게)
- 로켓단(컴퓨터) 점수: ❓ 칸에 멈추는 수에 조금 가산 (쫓아내려고). 쉬움은 그대로 무작위
- `validate()`에 `spots` 검사 추가

확률은 테스트할 수 있게 순수 함수로:

```js
Yut.Rewards = {
  BALLS: ["poke", "great", "ultra", "luxury", "master"],
  BOX_ODDS: [50, 30, 10, 5, 5],
  catchRate(ball),            // 0.60 + 0.05 × (단계 − 1), 마스터볼만 1.0
  rollBox(n, rnd),            // → ["poke", "great", ...]
  rollWild(pools, owned, rnd),// 희귀도 50/30/10/10 (WILD_ODDS) + 50% 미보유 우선 → id
  throwBall(ball, rnd),       // → { ok, shakes }  (실패면 흔들 1~3번)
};
```

난수: 윷 던지기 난수(판 시드)와 따로 쓴다 — 상자·조우 결과가 윷 결과 흐름을 바꾸지 않게. 뽑은 결과는 바로 저장.

### 5-3. 화면 (`index.html`)

| 곳 | 할 일 |
| --- | --- |
| 윷판 | ❓ 칸에 풀숲 도트 + 흔들리는 "?" 말풍선 (칸의 말을 가리지 않게 오른쪽 위). 조우 뒤 사라짐 |

| 윷판 패널 | 가방 요약 한 줄 |

## 7. 조심할 것

- **아이가 속상하지 않게**: 볼이 떨어져도 판은 그대로 계속된다. 놓친 포켓몬에게는 "다음에 또 만나자!" 같은 부드러운 말. 로켓단이 쫓아내는 건 재미 요소지만, 아이의 포켓몬을 뺏어 가지는 않는다
- **판 흐름이 길어지지 않게**: 조우는 판마다 최대 2번, 건너뛰기·그냥 보내 주기 있음
- **볼 경제**: 로켓단 1승 = 볼 3개, 판마다 ❓ 2칸. 몬스터볼(60%)로 3번 던지면 잡을 확률 약 94% → 조우 한 번에 볼 1~2개를 쓴다. 볼이 너무 빨리 쌓이면 상자 볼 수를 2개로 줄인다
